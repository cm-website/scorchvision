How It Works

1

Set Up Your Hardware

2

Download the App

Get ScorchVision from the App Store on your iPhone, iPad, or Mac device.

3

4

Compatible Hardware

ScorchVision works seamlessly with Raspberry Pi camera modules and compatible smart cameras. Set up your own DIY fire detection system with affordable, accessible hardware.

  • Works with Raspberry Pi Camera Module
  • Supports compatible IP cameras
  • Easy local network setup
  • No cloud dependency required

System Requirements

What you need to get started

Hardware

  • Raspberry Pi (any model with camera support)
  • Compatible camera module
  • Installed fire detection model
  • Local network access

Apple Devices

  • iPhone: iOS 15.6 or later
  • iPad: iPadOS 15.6 or later
  • iPod touch: iOS 15.6 or later
  • Mac: macOS 12.5 or later (Apple M1+)
  • Apple Vision: visionOS 1.0 or later
